URL 编码解码工具

把中文、空格和特殊字符转成百分号编码，也能把带 % 的 URL 还原成可读文本。

立即使用 URL 编解码

怎么用

  1. 输入中文或普通文本，点击「编码」得到 URL 编码。
  2. 输入带 %E4%BD%A0%E5%A5%BD 的字符串，点击「解码」还原原文。
  3. 结果可一键复制。

适用场景

  • 拼接带中文参数的 URL 查询字符串。
  • 调试前端跳转、分享链接和表单提交。
  • 查看短链接或接口地址中被编码的原始内容。

示例

你好 → %E4%BD%A0%E5%A5%BD
hello world → hello%20world

常见问题

URL 编码有什么用？

URL 只能安全传输部分字符，中文、空格和特殊符号需要转成百分号编码才能放进链接或请求参数。

URL 编码会上传内容吗？

不会。工具在浏览器本地运行，输入的内容不会离开你的设备。
