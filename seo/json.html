JSON 格式化工具

在线将乱成一团的 JSON 变成清晰可读的结构，也可以一键压缩减少体积，并即时校验语法是否正确。

立即使用 JSON 格式化

怎么用

  1. 把 JSON 文本粘贴到左侧输入框。
  2. 点击「格式化」得到带缩进的易读版本。
  3. 点击「压缩」得到去除空白的最短版本。
  4. 点击「校验」确认语法是否正确。

适用场景

  • 查看接口返回数据，快速找到嵌套结构和字段。
  • 调试前后端联调时把压缩 JSON 还原成可读格式。
  • 配置文件中需要紧凑 JSON 时执行压缩。
  • 交接代码前检查 JSON 是否符合标准。

示例

{"site":"拾贝工具箱","tools":["JSON","时间戳","Base64"],"free":true}

格式化后变成多行、带缩进的版本；校验时会精确提示错误位置，方便快速修复。

常见问题

JSON 格式化会泄露数据吗？

不会。工具完全在浏览器本地运行，内容不会上传到任何服务器。

JSON 压缩和格式化有什么区别？

格式化会加入缩进和换行便于阅读，压缩会移除所有空白字符以减少体积，两者内容语义相同。

支持 JSON5 或带注释的配置吗？

当前版本支持标准 JSON。带注释的配置请先转换或删除注释后再校验。
