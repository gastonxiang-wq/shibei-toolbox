JSON 压缩工具

把带缩进和换行的 JSON 压缩成一行，减小体积，适合配置文件和接口传输。

立即压缩 JSON

怎么用

  1. 把 JSON 文本粘贴到输入框。
  2. 点击「压缩」即可得到去除空白的最短版本。
  3. 点击「复制结果」直接取用。

适用场景

  • 把配置文件压缩成单行存储。
  • 减少前端传递 JSON 字符串的体积。
  • 把日志里的美化 JSON 压回紧凑格式。

示例

{"site":"拾贝工具箱","tools":["JSON","时间戳"],"free":true}

常见问题

JSON 压缩会改变数据内容吗？

不会。压缩只是移除空格、换行和缩进，字段名、值和结构都保持不变。

JSON 压缩后还能恢复吗？

可以。压缩版仍是合法 JSON，用格式化工具就能还原成带缩进的易读格式。
